# FitFlow Redesign - HCI Project

## 📱 Project Overview
FitFlow is a fitness tracking app redesign aimed at improving user retention, personalization, and engagement.

## 🎯 Problem Statement
- User retention dropped significantly
- App store ratings declined from 4.6 to 3.8 stars
- 68% of users abandoned the app during onboarding

## 🚀 Goals
- AI-powered personalized workout plans
- Social community features
- Improved nutrition tracking

## 🛠️ Tech Stack
| Layer | Technology |
|-------|------------|
| Frontend | Flutter |
| Backend | Node.js + NestJS |
| AI Service | Python FastAPI |
| Database | PostgreSQL + Firebase |
| Auth | Firebase Auth |
